# Akshat Ambasta Portfolio

Minimal editorial personal portfolio built with React, TypeScript and Vite. Includes CSS-first motion: hero type entrance, circular text orbit, marquee, scroll reveal, pointer-responsive energy schematic, and restrained animated closing orb. Respects `prefers-reduced-motion` and requires no animation libraries.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The Vite production output is `dist/`, suitable for Render Static Sites.
