# Akshat Ambasta Portfolio

A responsive personal portfolio built with React, TypeScript and Vite, deployed as a Render Static Site.

## Visual and interaction features

- Blackletter name treatment with pointer-reactive cyan/red chromatic slicing.
- Rotating orbit typography, a technical hero diagram and continuous editorial marquee.
- Custom desktop pointer follower and intersection-based scroll reveals.
- Stacked, scroll-aware service panels with perspective visuals across frontend, servers, AI/data and embedded/IoT.
- Interactive project gallery with Card/List view controls and project preview compositions.
- Pointer-responsive VoltVision schematic and animated solar-inspired closing orb.
- Reduced-motion support and mobile layout fallbacks.

## Featured work

- **VoltVision** — hardware/software energy-monitoring and intelligence prototype.
- **File2Base** — small-business file-to-database startup prototype.
- **Smart Plant Monitoring** — environmental sensing and automated farming exploration.
- **Carbon Emissions Calculator** — Python-based emissions estimation project.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The Vite production output is `dist/`, suitable for Render Static Sites.
